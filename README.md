# Chat Archive — Word & PDF

A local-only Chrome and Safari WebExtension for exporting ChatGPT content without subscriptions or usage limits.

## What works

- Export one ChatGPT response from the action row under that response.
- Export a complete conversation, with or without user prompts.
- Select individual user and assistant messages and export just those.
- Export the currently open ChatGPT Canvas editor.
- Export rendered Deep Research reports through the same rich-conversation capture path.
- Preserve headings, paragraphs, links, lists, tables, inline code, code blocks, quotes, images, vector graphics, and rich text.
- Convert common MathML structures generated by ChatGPT/KaTeX into editable Word OMML equations, including fractions, roots, scripts, limits, matrices, and fenced expressions.
- Preserve equations as native MathML in the PDF print document.
- Progressively scroll to the oldest message, then sweep through the full chat while caching turns. This supports long conversations whose messages are virtualized or loaded only while scrolling.
- Generate a real `.docx` file entirely in the browser. No server or office suite is required.
- Open a print-optimized document for PDF; choose **Save as PDF** in the browser's print dialog.

## Install in Chrome

For development:

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this project folder.
4. Open or reload a ChatGPT conversation.

For a clean package, run:

```sh
./scripts/package-chrome.sh
```

Then use `dist/chrome/` as the unpacked folder, or upload `dist/chat-archive-chrome.zip` to the Chrome Web Store developer dashboard.

## Install in Safari

Run:

```sh
./scripts/package-safari.sh
```

On recent Safari versions, open Safari Settings, enable the Developer tab if needed, select **Add Temporary Extension…**, and choose `dist/safari-extension/` or the Safari zip. Temporary extensions are for testing and Safari removes them after its temporary-extension lifetime.

For a permanent signed build, install full Xcode and rerun the script. It creates an Apple Safari Web Extension Xcode wrapper when Apple's packager is available. Open the generated project, configure signing, build the containing app, then enable **Chat Archive** under Safari Settings → Extensions.

## Use

- **Single response:** select the document icon in the response action row.
- **Whole conversation:** select the green **Export** control at the upper right, or use the toolbar popup.
- **Selected messages:** choose **Select**, mark the messages, then choose **Export**.
- **Canvas:** open Canvas first, then choose **Open Canvas** in the export dialog or toolbar popup.

Word downloads immediately. PDF opens the native print dialog so Chromium and WebKit can lay out fonts, MathML, tables, and images accurately; select **Save as PDF**.

## Architecture

The extension has no runtime dependencies and no build step:

- `src/content.js` discovers ChatGPT turns, captures virtualized conversations, manages UI, sanitizes content, and creates print documents.
- `src/docx.js` converts sanitized HTML and MathML to OOXML and writes an uncompressed standards-compliant ZIP container for `.docx`.
- `src/background.js` retrieves protected OpenAI-hosted images when page-level CORS prevents the content script from doing so.
- `src/content.css`, `src/print.css`, and popup files provide isolated extension and document presentation.

## Known boundaries

- ChatGPT changes its private DOM frequently. The implementation uses multiple role- and test-id-based fallbacks, but future ChatGPT redesigns may require selector maintenance.
- A PDF cannot be silently written by a normal consumer WebExtension without either rasterizing content or invoking print UI. This implementation deliberately uses the browser print engine for selectable text and high-quality math.
- Images hosted on unrelated third-party domains may refuse cross-origin fetching. They still appear in PDF when the browser can load them; Word falls back to image alternative text if embedding is blocked.
- Complex custom widgets that are neither HTML, SVG, canvas, nor images are exported as their accessible text.
